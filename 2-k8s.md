## Kubernetes files

These files are used to run the app on Kubernetes.

| Filename | Description | One word |
|---|---|---|
| `k8s/namespace.yaml` | Like renting a separate floor in a building just for your restaurant, so your stuff stays isolated from others. | Isolation |
| `k8s/backend-deployment.yaml` | Like hiring and managing your kitchen staff, deciding how many cooks should be working and replacing them if one leaves. | Workers |
| `k8s/backend-service.yaml` | Like the restaurant’s front desk, which sends customers to any available cook without customers needing to know who exactly serves them. | Routing |
| `k8s/backend-configmap.yaml` | Like the instruction board in the kitchen, holding normal operating settings such as timings or environment values. | Settings |
| `k8s/backend-secret.yaml` | Like the locker containing sensitive keys/passwords, only meant for trusted staff to use. | Secrets |
| `k8s/backend-hpa.yaml` | Like a smart manager who adds or removes cooks depending on how crowded the restaurant gets. | Autoscaling |
| `k8s/ingress.yaml` | Like the main entrance and signboard, deciding which type of customer goes to which counter or service inside. | Gateway |
| `k8s/postgres-deployment.yaml` | Like assigning a dedicated accountant/data clerk, whose job is to run and maintain the records system. | Database |
| `k8s/postgres-service.yaml` | Like the internal extension number for the accountant, so staff can always reach the records desk by one stable contact. | Access |
| `k8s/postgres-configmap.yaml` | Like the accountant’s non-sensitive setup sheet, such as which ledger/book to use. | Config |
| `k8s/postgres-secret.yaml` | Like the safe that stores the accountant’s vault password, not something posted publicly. | Credentials |
| `k8s/postgres-pvc.yaml` | Like reserving a physical filing cabinet that keeps records safe even if the accountant is replaced. | Storage |

### Very simple flow

- `Deployment` runs pods.
- `Service` gives a stable way to reach them.
- `ConfigMap` and `Secret` pass config.
- `HPA` scales pods up/down.
- `Ingress` exposes the app from outside.
- `PVC` keeps database data safe.

### Apply manifests

```bash
kubectl apply -f k8s/
```
